App Review notes — Prosper Remote Terminal

WHAT THE APP DOES
Prosper attaches to terminal sessions running on the user's own Mac (which runs
the companion Prosper desktop app) and streams them to iPhone/iPad. The phone and
Mac communicate over the user's private Tailscale network — terminal traffic flows
directly device-to-Mac and does not pass through any service we operate.

Two OPTIONAL features need an account: "Remote Wake", which lets a signed-in user
wake their own sleeping Mac, and "Live status and alerts" (below). Everything else
(terminal, demo) works fully signed-out.

HOW TO REVIEW WITHOUT A MAC OR TAILSCALE
You do not need any external setup, and you do NOT need to sign in. The app ships
with a fully offline DEMO:

  1. Launch the app. Tap "Remote Terminal".
  2. On the "Machines" screen, tap "Try the demo" (bottom of the list).
  3. Tap the "Demo session". A sample terminal session opens and is fully
     interactive — the on-screen keyboard and shortcut bar work; typed text is
     echoed. (No real shell runs on-device; iOS sandboxing prevents that, which
     is exactly why real sessions are hosted on the user's Mac.)

The "?" button (top-right on the home and Machines screens) opens an in-app
"How it works" guide explaining the Prosper + Tailscale model.

WHAT'S NEW IN THIS VERSION, AND WHERE TO SEE IT IN THE DEMO
  - Compact keyboard and two-row shortcut bar: open the Demo session and tap
    into the terminal.
  - Copy mode: drag a finger over the terminal text in the Demo session.
  - Insert: the "insert" key (cursor icon) on the shortcut bar opens a compose
    sheet; its text is sent to the session.
  - Helper-task count in the session list: each session row can show how many
    helper tasks are running. The count only appears for sessions on a real Mac
    running Prosper, so it is not visible in the demo.
  - Live status and alerts (see below). Not visible in the demo.
New in this version: the notification permission, asked only after the user
taps "Turn On". No new data collection, accounts or purchases are added.

LIVE STATUS AND ALERTS (NOTIFICATIONS AND LIVE ACTIVITY)
After signing in, the home screen offers "Turn on notifications" (Turn On / Not
now); Settings has a "Live status and alerts" switch. Turned on, the app registers
for push notifications with our server, which pushes:
  - a Live Activity (Lock Screen and Dynamic Island) for the user's Mac while
    its agent sessions are working, showing session names, their states and
    counts. If updates stop arriving it reads "status unavailable" instead of
    old states, and it shows when the Mac is offline;
  - a notification only when a session needs the user. Tapping it opens that
    session.
Only session names and states are sent, never terminal content. Both need the
user's own Mac running Prosper and signed in to the same account, so neither can
appear in a review environment; the demo has no Mac and sends nothing. Turning
the switch off, or signing out, removes the device's registration from our
server and ends the Live Activity.

ABOUT THE OPTIONAL "WAKE" BUTTON
The Wake button only appears when the app actually FAILS to reach a real, saved
Mac (i.e. that Mac is asleep/unreachable). In a review environment there is no
real Mac on your tailnet, so this surface is not reachable through normal use and
is EXPECTED to be non-functional. Wake requires signing in (passwordless email
magic link) and only ever wakes a Mac the same account owns. The terminal and
demo do not depend on it.

ACCOUNTS / SIGN IN
Sign-in is passwordless: the user enters an email address and taps a one-time
magic link. We do not use third-party sign-in, and "Sign in with Apple" is not
required here because we do not offer any third-party/social login option
(Guideline 4.8 does not apply — email is our only login mechanism and is used
solely to operate the optional Remote Wake and live status features).

ACCOUNT DELETION
A signed-in user can delete their account in-app: Settings → Delete Account. This
permanently removes their account and remote-wake data from our server and signs
the device out.

ENCRYPTION
Uses only standard/exempt encryption (standard TLS, no proprietary crypto).
